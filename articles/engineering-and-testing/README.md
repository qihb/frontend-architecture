# 工程化、测试与 AI——web前端研发效能提升实战

本专栏围绕web前端工程化、自动化测试和 AI 辅助研发三条主线，系统梳理从构建到部署、从测试到质量保障的完整链路，并探讨 AI 在代码生成、测试编写、代码审查和 CI/CD 中的落地实践。

## 专栏定位

- **工程化篇（第 1–6 篇）**：从构建工具演进到 CI/CD 流水线，覆盖前端工程化的核心环节
- **测试篇（第 7–10 篇）**：从测试策略到落地实践，建立分层测试体系
- **AI 篇（第 11–14 篇）**：从 AI 辅助编码到智能工程化，探索 AI 如何重塑研发流程
