# 第十四篇：表单设计器实战——字段拖拽、校验配置与联动编排

**核心要点：**

- 低代码三大件之一：页面搭建、流程编排之外，表单设计是企业应用里体量最大、ROI 最高的搭建场景
- 核心挑战：字段拖拽 + 布局排列 + 校验规则 + 联动逻辑，四类需求叠加后的复杂度控制
- 表单组件体系：基础组件（输入框、数字框）、选择组件（下拉、单选、多选）、高级组件（日期、文件上传、富文本、子表单）
- 布局方案：单列、多列栅格与分组容器——直接复用第十篇的栅格布局模式与三栏结构
- 校验规则可视化配置：必填、正则、自定义校验函数与错误提示的 Schema 表达
- 联动逻辑：字段显隐、取值联动（"省份"变化联动"城市"）、跨字段校验——表达式驱动 vs 编排驱动两种方案
- 表单 Schema 与渲染对接：在第十篇协议上扩展字段描述，复用第十一篇的渲染引擎与物料体系
- 生态参考：Formily、amis、VForm 的协议设计与实现取舍

**这篇适合谁看：**

- 要在低代码平台中补齐表单设计能力的团队
- 被"校验/联动配置越做越乱"困扰的表单平台开发
- 在 Formily、amis、VForm 之间做选型评估的技术决策者
