# 第六篇：拖拽中的数学——坐标系、缩放与 Figma 式无限画布

**核心要点：**

- 世界坐标 vs 屏幕坐标：getBoundingClientRect 的真相，缩放后"拖拽偏移"经典 bug 的根因
- 画布变换：transform: translate + scale 复合变换的推导，围绕鼠标点缩放（zoom at cursor）的公式
- 逆变换：屏幕坐标 → 画布坐标的正确换算，为什么在嵌套缩放时简单除以 scale 不够
- 滚轮缩放与平移：wheel 事件的 ctrlKey 区分、缩放范围限制、平移的边界处理
- 分层画布结构：背景层（网格）/ 内容层（节点）/ 交互层（选框、参考线）的 DOM 设计与各层坐标系
- 从手写排序到画布交互的思维跃迁：一切几何计算都要在"世界坐标系"里完成

**这篇适合谁看：**

- 要做画布类需求（大屏、白板、流程图、低代码画布）的同学
- 被缩放后拖拽偏移、命中不准折磨过的工程师
- 想理解 Figma/Miro 无限画布底层原理的同学
