# 番外篇四：一次拖拽卡顿的生产排查——性能剖析实战案例

**核心要点：**

- 案例背景：低代码大屏画布拖拽掉帧，节点 800+，缩放后拖拽"跟手但不跟帧"
- 排查路径：Performance 录制 → Long Task 定位 → 强制同步布局（forced reflow）→ getBoundingClientRect 风暴
- 根因复盘：mousemove 里逐节点读取 rect + 修改样式的读写交错，触发布局抖动；参考线候选集全量遍历雪上加霜
- 修复过程：rect 批量缓存、rAF 合帧、空间索引（呼应第八篇）、hover 框单实例化（呼应第十二篇）
- 效果度量：帧率从 xx 提升到 60fps、Long Task 数量与最长耗时的前后对比
- 方法论沉淀：拖拽性能问题的标准排查清单与预防性规约（评审时看什么）
