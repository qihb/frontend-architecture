# 第十三篇：流程图编辑器实战——节点、连线与自动布局

**核心要点：**

- 图编辑器领域模型：Node、Edge、Port 与图数据结构（邻接表 vs 边列表），和 DOM 树结构的本质差异
- 连线交互：从端口拖出连线、连接合法性校验（方向/类型/成环检测）、动态锚点
- 边的路由算法：直线、平滑贝塞尔曲线、正交折线与避障路由的原理与取舍
- 自动布局：dagre 层次布局原理（分层 + 去环 + 排序），在审批流/编排场景的应用
- 发布前流程校验：孤立节点检测、必填配置检查与错误定位，导出 BPMN 或自定义 JSON 对接下游系统
- 技术栈对比与选型：AntV X6（2.x）、React Flow（已更名 @xyflow/react）、LogicFlow 的架构差异、扩展能力与适用场景，含维护状态与版本现状
- 与前文打通：流程图编辑器 = 无限画布（第六篇）+ 命中检测（第七篇）+ Undo（第九篇）的组合实战

**这篇适合谁看：**

- 要做审批流、任务编排、CI 配置等图编辑场景的同学
- 在 X6 / ReactFlow / LogicFlow 之间纠结的团队
- 想系统理解"图"这一类编辑器与画布编辑器差异的工程师

**配图计划：**

- Node/Edge/Port 图数据结构示意图
- 三种边路由算法对比图（直线/曲线/折线避障）
- dagre 层次布局的分层过程图
