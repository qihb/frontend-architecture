# 第十一篇：低代码编辑器架构（下）——物料体系、渲染引擎与代码生成

**核心要点：**

- 物料协议：组件描述（props/setter 配置）、物料分组、物料市场与远程物料加载
- 设计态 vs 运行态：选中态/悬停态如何不污染业务组件（HOC 注入 / Context / data 属性三种方案对比）
- 渲染引擎：递归渲染 Schema、插槽（children 具名坑位）、循环容器、条件渲染的实现
- 数据绑定与数据源：表格绑定 API、参数映射与请求缓存，让组件运行在真实数据上
- 画布中的组件与真实运行的组件：iframe 隔离、同构渲染、沙箱的取舍
- 出码之争：AST 代码生成 vs 运行时渲染，各自的工程价值、局限与混合路线
- 物料研发工作流：从组件开发到物料接入的完整链路与调试体验

**这篇适合谁看：**

- 已有编辑器骨架、要搭建物料体系的团队
- 纠结"到底要不要出码"的技术决策者
- 负责渲染引擎与物料生态的核心开发
